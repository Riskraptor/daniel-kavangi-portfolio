# Daniel Mwendwa Kavangi Portfolio

Personal portfolio website for **Daniel Mwendwa Kavangi** built with **React + Vite** and deployed on **Vercel**.

Live site: [https://daniel.kavangi.co.ke](https://daniel.kavangi.co.ke)

## Tech stack

- React
- Vite
- React Router
- Tailwind CSS

## Project structure

- `src/components` reusable UI components
- `src/pages` routed pages (Home, About, Work, Experience, Education, Contact)
- `src/data/portfolioData.js` portfolio content and SEO metadata
- `src/lib/contact.js` contact form validation and delivery logic
- `api/contact.js` serverless contact endpoint for Vercel
- `public/` static assets served as-is

## Getting started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deployment

This project is configured for deployment on Vercel from the repository root.

## Domain

Production domain: `daniel.kavangi.co.ke`
